## Resumen del proyecto
**Sistema de tickets** - Gestion interna de bugs para apps "Balances" y "Financiamiento" (financiamiento politico).
- **Fase 1 (completa)**: Tickets convencional - login, listado, creacion, detalle, comentarios, adjuntos, toma colaborativa, cambio de estado, admin de sistemas/accesos.
- **Fase 2 (parcial)**: Analisis conceptual IA via LLM - modo manual (boton Analizar/Reanalizar). Providers Groq/Gemini/OpenRouter/NVIDIA/Ollama con llamada HTTP real. **Prompt optimizado** (system/user separados, texto plano sin HTML, contexto de ticket/sistema, defensa anti-prompt-injection). **Pendiente**: admin de versiones de prompt (el resto de ítems IA quedó en "Por ahora no").
